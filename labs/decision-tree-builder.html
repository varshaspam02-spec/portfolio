    How the tree is grown

    Greedy CART-style splitting. At each node the builder tries every feature, keeps the single split with the largest impurity drop (the gain), then repeats on both halves. It never revisits an earlier choice.

    Two kinds of question. Numeric features are cut at midpoints between neighbouring values. Categorical features test one category against all the others.

    Impurity. Gini or entropy for classification, mean squared error for regression. A pure node scores 0.

    Stopping. A node becomes a leaf at max depth, below min split rows, when the best gain is under min gain, or when it is already pure.

    Missing values. Empty cells count as missing. A row missing the split feature is left out of both branches while training, and follows the no branch when traced.
