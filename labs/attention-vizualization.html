      Reading guide

      Attention(Q, K, V) = softmax(QKT / √dk) · V

      Queries, keys, values. Every token is projected three ways. Its query is compared with every key, and the dot products are scaled by the square root of the key size to give one row of scores.

      Row-wise softmax. Softmax turns each row of scores into weights that sum to 100%, so a row reads as where that token looks. The output mixes the values by those weights.

      Heads. A layer runs several heads side by side, and each can pick up a different relationship. The four heads here are hand-made patterns with random noise, not learned weights.
